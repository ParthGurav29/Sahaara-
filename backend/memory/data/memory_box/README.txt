# Memory Box Clips

This directory stores pre-recorded audio clips from family members.

## Current clips

- `priya_hello.mp3` — placeholder (0 bytes). This is NOT Priya's real voice.
  A real clip must be recorded by the actual family member with their
  informed consent. The clip should be a short, warm greeting that the
  person with dementia can listen to when they miss that family member.

## Rules

- Clips are played only after Sahaara OFFERS and the user accepts.
- Never play a clip without offering first.
- Never impersonate a family member — the clip is framed as "something
  Priya left for you," not "this is Priya speaking to you now."
- Clips must be caregiver-approved and consent-gated.
- Voice cloning of living people for free-form generation is roadmap only.
